# Sistem Informasi Persebaran Penyakit ISPA di Jakarta Selatan

Selamat datang di repository Sistem Informasi Persebaran Penyakit ISPA di Jakarta Selatan.

Website ini dibuat untuk menyajikan informasi mengenai persebaran penyakit Infeksi Saluran Pernapasan Akut (ISPA) di wilayah Jakarta Selatan dalam bentuk tampilan yang sederhana dan mudah dipahami. Website ini dikembangkan menggunakan HTML sebagai bagian dari tugas pembelajaran pembuatan website.

## Tujuan
Menyajikan informasi persebaran ISPA agar lebih mudah dilihat dan dipahami melalui media digital.

## Teknologi
- HTML
